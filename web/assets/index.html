Startseite

Reihenfolge, Name und Icon je Kachel — wird bei jeder Änderung sofort gespeichert. Der Katalog in „Alle Apps“ auf dem Fernseher bleibt unverändert.

    Darstellung

    Alle Einstellungen der App: Hintergrund, Anordnung, Akzente, Uhr, Sprache, Senioren-Modus, Bildschirmschoner. Jede Änderung wird sofort gespeichert und der Fernseher zieht sie im laufenden Betrieb nach.

    Home Assistant

    Adresse und Token bleiben auf dem Fernseher; das Token wird beim Lesen nicht zurückgegeben.

    Entitäten auf der Kachel

    Bis zu 12 Werte. Gespeichert wird nur die Auswahl, das Token bleibt auf dem Fernseher.
