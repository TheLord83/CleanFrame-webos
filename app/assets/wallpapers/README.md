# Launcher wallpapers

The fifteen entries in `SOURCES.json` each have a background JPEG, a thumbnail and a small blurred panel backdrop. Four registered material JPEGs per image live in `../materials/`. All derived images retain the source photograph's terms.

Photo pages, authors, licence observations and the sizes of every derived file are in [asset sources](../../../docs/asset-sources.md), the derived images in [its last section](../../../docs/asset-sources.md#derived-images). Full-size originals remain outside the repository.
